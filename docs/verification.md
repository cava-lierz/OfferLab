## 人工验收步骤

1. 停止原本机开发进程，再执行 `bash scripts/dev.sh`；真实模式保持 SSH 隧道运行。
2. 创建面试：应先看到“材料已保存”与生成状态，模型返回后展示计划并等待确认。
3. 回答一道题：应及时看到已保存回答及下一题生成状态；等待期间回到历史记录，再返回，耗时与任务继续。
4. 在回答框输入草稿后刷新：草稿应恢复。两个标签页尝试回答同一问题，应只保存一次；失败重试相同内容也不应重复保存。
5. 生成报告期间刷新、离开页面、回看问答；完成后自动出现报告，校验原文引用和 Markdown 导出。
6. 暂停后端或断开浏览器连接，确认提示状态更新中断；恢复后应重新查询。正常停止后端时，运行任务应标记中断，材料与回答仍在；排队任务下次启动继续。
7. 临时关闭自己启动的隧道，确认模型失败后显示明确错误；恢复隧道后在原记录重试，不重复保存回答。
8. 检查桌面和 390px 手机视口、键盘操作、长文本、减少动态效果设置，以及上传文本型 PDF 的实际解析质量。
