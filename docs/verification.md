# 测试与验证记录

截至 2026 年 11 月 28 日，我能从现有记录确认两项结果。本地演示模式已在浏览器中完成两道主问题、每题一次追问、手动切题和四维复盘。学校端的运行轨迹分别记录了专用面试官读取评分标准、调用搜索工具检索公开面经。个人 DeepSeek 从备课到生成合格报告、再到导出的整场表现，仍缺少一次完整的端到端验收。

## 11 月 25 日 · 学校模型连接与 Agent 路由

05:30 UTC 的本机接入检查通过 SSH 隧道访问学校 OpenClaw `2026.5.22`。健康接口用了 0.01 秒，最小模型调用用了 10.61 秒，返回 HTTP 200，且 `completion_present=true`。随后一场真实面试生成了 5 道主问题，数据库记录进入 `active`，`error=null`。

学校端安装器返回 `validated_by_openclaw: true`，工作区指向 `/home/idekube/.openclaw/workspace-interviewer`。学校 CLI 的 Agent 与 Skill 列表均已识别专用面试官，本机配置也指向 `interviewer`。一次报告任务的脱敏轨迹确认实际执行者为 `interviewer`，模型为 `deepseek-reasoner`。它在约 22.7 秒时成功调用 `read` 读取 Skill 与评分标准。当时复制的学校默认模型配置为 `sjtu/deepseek-reasoner`。

这次报告在约 114.9 秒时中止，此前另一份在约 113 秒时中止，两次都没有报告正文。当时请求时限是 120 秒，后来报告改用独立的 300 秒默认时限。旧记录能说明中止发生在哪个阶段，新时限下的完成率仍待测量。

执行 `bash scripts/check.sh` 后，60 项后端测试、7 项前端测试全部通过，TypeScript 检查和 Vite 生产构建通过。后端 60 项包括核心流程 23 项、后台任务 9 项、ASGI 接口 5 项、模型适配 11 项、安装打包 10 项和脱敏诊断 2 项。

在模型生成被阻塞的测试中，提交接口仍然返回 202，GET 可以读到已保存的回答，相同的请求重复提交也只保留一份记录。这一批测试还覆盖了从排队任务恢复、心跳失联、停机撤销写入权、旧任务迟到以及上传错误、引文导出。前端测试检查了版本合并、当时的等待状态、草稿恢复和回答回看。

接口测试通过 httpx 在进程内运行真实的 FastAPI lifespan、SQLite 和 JobRunner。为绕过当时环境里 TestClient 线程桥等待的问题，测试直接调度短同步接口，后台线程另作验证。真实 Uvicorn 网络和 FastAPI 线程池调度仍需联机检查。前端当日使用 React 服务端渲染，当时的运行环境也限制了依赖下载和端口访问。桌面和手机浏览器的结果来自次日的独立检查。

## 待完成的真实面试验收

完整验收计划采用虚构简历、明确的目标岗位和轮次，设置两道主问题。本机保持 SSH 隧道在线，以 `python3 scripts/manage.py dev` 启动 OpenClaw 模式。下表是后续验收的判定条件。

| 验收项 | 判定条件 |
| --- | --- |
| 备课 | 准备页显示等待状态与备课来源，开始前隐藏题目。第一题应与目标岗位和轮次相关。 |
| 提交与切题 | 输入草稿后刷新可恢复。两个标签页提交同一题只保存一份回答。结束追问后可切到下一道主问题，并回看此前问答。 |
| 真实报告与导出 | 离开页面后可恢复报告任务。成品包含四项反馈，每项评分的引文可在对应回答中找到。Markdown 应保留维度、来源和完整问答，同时记录模型、工具调用与耗时。 |
| 中断恢复 | 浏览器断线后出现重连提示。后端停机后，运行中任务标记中断，排队任务重启后继续。隧道中断后恢复连接并重试，已提交回答仍只保留一份。 |
| 输入与阅读 | 以长回答、文本型 PDF、键盘操作和减少动态效果设置检查实际体验，覆盖桌面和 390px 手机视口。 |

诊断命令中，`python3 scripts/manage.py gateway-check` 会发起一次最小模型调用，`python3 scripts/manage.py runs` 通过 SSH 读取已有运行摘要。两份脱敏输出均保存在私有的 `data/` 目录。[本机运行与排查](operations.md)
