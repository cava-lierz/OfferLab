# OfferLab · AI 模拟面试与复盘系统

OfferLab 是我们两人为《大模型与智能体工程实践》课程开发的文字模拟面试系统。我希望练习者在面试结束后能看出，哪些回答已经讲清了个人贡献，哪些地方还缺少依据。因此，系统在每项评分旁列出候选人的原话，方便把反馈和当时的回答放在一起看。[课程要求](requirement.png)

## 面试流程

**准备材料。** 候选人填写目标岗位，提交简历，可补充岗位描述（JD），并选择 1–5 道主问题。简历支持粘贴文本、上传 TXT 或文本型 PDF。课程演示内置了一份产品经理实习生的虚构简历，其中提到了校园二手交易小程序、用户访谈和发布表单设计。

**逐题作答。** 面试官提前拟定主问题，页面在面试开始后逐题展示。候选人每提交一次回答，系统先保存原文，再判断是否需要追问。每道主问题最多追问两次。候选人可以从历史记录继续未完成的面试，也可以在至少提交一次回答后提前结束。

**面试复盘。** 报告从表达结构、项目深度、岗位匹配和反思能力四个维度给出反馈和练习建议。每项有分数的评价必须附上本场回答的连续原文。候选人可以对照完整问答阅读报告、导出 Markdown，或选择某项建议作为下一场的练习重点。

## 运行方式

我把页面、面试进度和记录放在本机，把需要模型判断的工作交给学校已有的 OpenClaw。浏览器访问 React 页面，FastAPI 负责把材料和回答存入 SQLite，并经 SSH 隧道向学校 Gateway 提交请求。学校的专用面试官 `interviewer` 可以在备课时检索公开面经，按需读取原文。采用的网页列在备课来源里，候选人的评分依据则来自实际回答。[架构与接口约定](docs/architecture.md)

系统还提供本地演示模式。它使用固定题库和追问规则，可以在学校服务离线时演示从准备到导出的全过程。演示报告保留回答引文，四个维度均显示「未评分」。

## 本机启动

运行环境为 Bash、Python 3.11+（含 venv 和 pip）、Node.js 22.12+ 及 npm。启动命令在项目根目录执行。

```bash
python3 scripts/manage.py dev
```

脚本会安装缺失的依赖，并在首次缺少 `.env` 时创建演示配置。前端地址为 `http://127.0.0.1:5173`。OpenClaw 模式还需要一条到学校的 SSH 隧道。项目面向本机单用户练习，运行记录保存在 `data/`，私有配置保存在 `.env`。启动终端收到 Ctrl+C 后会关闭前后端。[本机运行与排查](docs/operations.md)
